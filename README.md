# OSC Console v2.5

uOSC向けWebコントロールサーフェスです。

## UI
- シンプル: 4CH
- カスタム: 最大32CH、4CHごとのBANK
- DCA ON FADERS: 各CHのDCA影響率を0〜100%で設定
- DCA MASTER: 全体のDCA倍率を設定
- MAXボタン: CH最大値またはDCA 100%へ移動
- フェーダーは0・50・100を含む全域でスナップせず連続的に動作します
- 数字タップで直接入力できます
- ブラウザ振動機能は使用しません

## OSC
- 高頻度数値制御の初期Port: 3336
- Addressは小文字・スラッシュ区切り・英数字とハイフンのみ
- 同一LANとクラウド中継に対応
